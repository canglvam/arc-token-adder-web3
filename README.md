# 🦊 Arc Testnet Token Adder (Arc 测试网代币一键添加工具)

## 📖 简介

这是一个轻量级、去中心化（DApp前端）的 Web3 实用小工具，专为加密货币玩家和空投交互者设计。
你可以通过它**一键将指定的 Arc 测试网代币（如 cirBTC, USDC, EURC, MTK 等）**快捷安全地添加到你的 MetaMask、OKX Wallet 或其他支持 EVM 兼容的浏览器钱包中。

🌐 **在线体验 / 永久访问链接**: [https://canglvam.github.io/arc-token-adder-web3/](https://canglvam.github.io/arc-token-adder-web3/)

## ✨ 核心特性

- **🚀 零服务器 (Serverless)**: 这是一个纯静态的 HTML/JS 网页，无需任何后端数据库或服务器支持，打开即用，响应极快。
- **🔒 绝对安全**: 代码完全开源且全部在你的浏览器本地执行。它只向钱包发送添加代币的请求 (`wallet_watchAsset`)，绝对不会、也没有能力触碰你的私钥或发起任何授权转账操作。
- **🌐 全平台 & 多开兼容**: 完美兼容原生 Chrome、Edge，以及各种**指纹浏览器**（AdsPower、BitBrowser等）。你可以将网址丢进任意浏览器，支持同时在 100+ 个多开分身中并发执行。
- **🤖 智能钱包嗅探 (EIP-6963)**: 采用最新的 EIP-6963 协议以及底层数组保底扫描机制。即使你的浏览器里同时安装了小狐狸、OKX、Coinbase 多个钱包相互冲突，它也能精确把它们全部“揪”出来供你下拉自由选择。

## 🛠️ 如何使用？

1. **准备工作**: 确保你的当前浏览器中已经安装并解锁了 Web3 钱包插件（如 MetaMask）。
2. **打开网页**: 访问上面的 [在线工具链接](https://canglvam.github.io/arc-token-adder-web3/)。
3. **选择钱包**: 在“步骤 1”的下拉菜单中，选择你想要激活的钱包。
4. **一键添加**: 在“步骤 2”中，找到你需要的代币，点击橙色的“一键添加”按钮。
5. **钱包确认**: 你的钱包插件会自动弹出，点击“添加代币”即可大功告成！

## 👨‍💻 技术原理

本项目采用了极简架构，没有任何冗余的构建工具或依赖：
- 原生 HTML5 + CSS3 构建了干净的 UI 界面。
- Vanilla JavaScript (原生纯 JS) 处理交互逻辑。
- 通过调用以太坊官方推荐的 Provider API (`window.ethereum.request`) 实现与各类钱包插件的底层通讯。

## 📄 扩展与修改
本项目极其轻量且代码开源。如果你想修改自己喜欢的代币：
只需打开 `index.html` 源码，复制其中一个 `<div class="token-card">...</div>` 代码块，把里面的代币名称、智能合约地址 (`address`) 以及小数精度 (`decimals`) 替换成你想要的代币即可！
